# 五十心所 · 每日省察

唯识心所日志打卡与自我检测工具（PWA 静态网页，纯前端、无后端、无依赖）。

> **设计理念**：理论学习再详细，终究要记录比对在行动里。每日以五十一心所中关键内容为镜，
> 省察自心起念：善心所与不善心所分单元对照，「择善去非」正是心性修养，保持心理健康的日常功夫。

## 功能

### 一、今日打卡
- **单元一 · 择善（善心所对照，11 条）**
  信、惭、愧、无贪、无嗔、无痴、精进、轻安、不放逸、行舍、不害，
  各与其对治之不善心所（不信、无惭、无愧、贪、嗔、痴、懈怠、惛沉、放逸、掉举、害）并观，
  每日自择所处：**善现前 / 平·无记 / 恶现前**。
  > 「无惭愧及不信等，与上善法相返，义相对照可知。」——憨山《百法论义》
- **单元二 · 去非（独立不善心所，15 条）**
  慢、疑、恶见、忿、恨、覆、恼、嫉、悭、诳、谄、憍、失念、散乱、不正知，
  逐条省察今日显现之轻重：**未现 / 微现 / 明显 / 炽盛**。
- **省思札记**：今日省思 + 明日所修，落在文字，对照行动。
- 保存后即时给出当日**善分（/11）、不善分（/45）与日评**。

### 二、回顾
- 统计卡：累计打卡、连续打卡、近 7 日善分均值与不善均分
- 三十日趋势双线图（善分 / 不善分）
- 近三十日**不善心所排行**（问题所在）与**善法现前排行**（进步所在）
- 打卡日历（按日评着色，点击日期可回看补记）
- 数据导出 / 导入备份（JSON）、清空

## 义理依据
| 内容 | 出处 |
|---|---|
| 六位心所分类与定义 | 玄奘译《成唯识论》卷五、卷六（依个人笔记《成唯识论纲要》） |
| 善法与不善法对治关系、按语 | 憨山德清《百法论义》 |

在佛法唯识学的体系中，“五十一心所”（全称“五十一心所有法”）是对人类复杂心识活动和精神状态的精细分类。它们是依附于“心王”（即八识：眼、耳、鼻、舌、身、意识、末那识、阿赖耶识）而生起的心理作用，不能独立存在，必须与心王相应俱起。
五十一心所按其性质和作用范围分为六大类（称为“六位”），这一体系主要确立于《大乘百法明门论》和《成唯识论》中。以下是完整的分类与详解：
一、 遍行心所（5个）
“遍行”意为遍一切时、遍一切处、遍一切识。只要心王生起，这五种心的作用必定同时存在，是构成一切心识活动最基础的元素。
作意：警觉心识，将注意力引向特定对象。
触：根（感官）、境（对象）、识（心王）三者和合而产生的初步接触。
受：领纳境界，产生苦、乐、舍（不苦不乐）的感受。
想：摄取对象的形象，形成概念和语言（即“表象”作用）。
思：驱使心识造作善、恶或无记（非善非恶）行为的意志与动机。

二、 别境心所（5个）
“别境”指这些心识作用并非在所有情况下都出现，而是只在特定情境下，针对特定对象才会生起。

欲：对期望的事物产生希望或追求的意愿。
胜解：对已决定的道理或境界，产生确定不移的信解与印可。
念：对曾经经历的事物，能够清晰记忆而不忘失。
定：将心专注於一个对象上，保持稳定不散乱（三摩地）。
慧：对所观察的对象进行简择、推度、判断的智慧作用。

三、 善心所（11个）
这些是与善行相应的正面、清净的心识作用，能对治烦恼，带来安乐的果报。

信：对真理、因果或功德产生清净的认同与崇敬。
精进（勤）：在修善断恶的过程中，努力不懈、勇猛向前。
惭：依自身内在的良知，对自己的过错感到羞耻。
愧：顾及世间舆论或他人看法，对自己的过错感到羞愧。
无贪：对世间五欲（财、色、名、食、睡）不贪著。
无嗔：对违逆的境界不起愤怒，保持慈悲与平和。
无痴：明达事理，不愚昧，具有正确的认知。
轻安：身心远离粗重烦恼，感到轻松、安适与调畅。
不放逸：时时警惕，不懈怠放纵，专心防护恶法、修习善法。
行舍：舍弃昏沉、掉举等不平等心态，令心保持平静、中正。
不害：基于慈悲心，不损恼、不伤害一切有情众生。

四、 根本烦恼心所（6个）
这是所有烦恼的根源，又称“六根本烦恼”，能障蔽清净本性，引发痛苦。

贪：对顺心、喜爱的境界产生染著与占有的欲望。
嗔：对逆心、不喜爱的境界产生憎恶与愤怒。
痴（无明）：对事理迷惑，不能明辨是非善恶，是一切烦恼的根本。
慢：贡高我慢，自认优越而轻视他人。
疑：对佛法真理、因果法则等犹豫不决，产生怀疑。
不正见（恶见）：错误的见解，包括身见、边见、邪见、见取见、戒禁取见等。

五、 随烦恼心所（20个）
由根本烦恼衍生出来的次要烦恼，按其活动范围和强度分为三类：

小随烦恼（10个）：行相粗猛，各别而起，不能同时生起。

忿：因愤怒而表现于外的暴恶状态。
恨：将忿怒怀藏在心，结怨不舍。
覆：隐藏自己的过错，怕被他人知道。
恼：因忿恨而变得暴戾，或发粗恶言语。
嫉：对他人的成功或优点心生妒忌。
悭：吝啬财物或佛法，不愿与人分享。
诳：为了欺骗他人而诈现不实的功德或才华。
谄：曲意奉承，讨好他人以掩盖过失。
害：缺乏悲悯，损恼有情众生。
憍：依仗自身的长处（如年轻、健康、财富）而沾沾自喜。

中随烦恼（2个）：遍于一切不善心，是道德感缺失的表现。

无惭：对自己的过恶不感到羞耻。
无愧：对自己的过恶不觉得对不起他人。


大随烦恼（8个）：遍于一切染污心（不善及有覆无记），影响范围广。

不信：对善法不认同、不清净、不希求。
懈怠：懒惰，不努力修善断恶。
放逸：放纵自己，不防护身心，增长恶法。
昏沉：身心沉重，缺乏堪能性，障碍观照（毗钵舍那）。
掉举：心念浮动不安，回忆可爱境界，障碍禅定（奢摩他）。
失念：遗忘正法，无法明记所缘之境。
不正知：对所观察的事物产生错误的认知或理解。
散乱：心念流散，无法专注於一境。

六、 不定心所（4个）
“不定”指这些心识作用的善恶属性不固定，可善、可恶、或无记，取决于它们与何种心所相应俱起。

悔（恶作）：对已做或未做的事感到追悔（如后悔做恶事为善，后悔做善事为恶）。
眠（睡眠）：令心暗昧、收敛的生理/心理状态，适度为善，过度为恶。
寻：心识对境界进行粗略的推求、思考。
伺：心识对境界进行细致的观察、伺察。

唯识学划分“五十一心所”的核心目的
唯识学并非为了纯粹的心理学研究而分类，其根本目的是 “转识成智” 的修行实践：

精准对治：只有清晰地识别出内心生起的是哪一种“心所”（如察觉到自己正在经历“掉举”或“悭”），才能用相应的善法（如“定”或“无贪”）去对治它。
破除我执：通过分析证明，所谓的“我”或“心”，不过是这51种心理因素在因缘和合下的刹那生灭，并无一个恒常不变的实体，从而瓦解对“自我”的执着。
指导禅修：在止观修行中，修行者需要依靠“遍行”和“别境”中的“定”与“慧”，同时剔除“大随烦恼”中的昏沉与掉举，最终引发“善心所”中的“轻安”，证入清净境界。
